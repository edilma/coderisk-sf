# Project Assets

Documentation and media assets for the Property Risk Intelligence Platform.

## Contents

- **screenshots/**: Application interface screenshots for documentation
- **diagrams/**: Technical architecture and workflow diagrams  
- **videos/**: Demo recordings and presentation materials

## Usage

Assets are referenced in project documentation using relative paths:
```markdown
![Description](assets/screenshots/filename.png)
```

All media assets support the project's technical documentation and demonstration materials.
